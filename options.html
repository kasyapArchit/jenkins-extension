Jenkins Launcher

Point the extension at your Jenkins controller once, then star pipelines from the popup. Everything below the connection saves as you change it.

CONNECTION
No trailing job path. Include the context path if Jenkins sits behind a proxy, for example https://ci.example.com/jenkins.
API token requests are exempt from Jenkins CSRF checks. Session mode needs you logged in to Jenkins in this browser and fetches a crumb per build.
Create one at /me/security on your Jenkins.
STATUS TRACKING
Saves automatically.
Chrome will not fire alarms faster than every 30 seconds. While the popup is open, elapsed times still tick every second.
SUBSCRIPTIONS
Saves automatically.

Subscribe to a pipeline from the bell in its parameter panel and you are notified whenever it runs, whoever started it. These choose which moments are worth a notification; at least one has to stay on.

Notifications only arrive while Chrome is running and the controller is reachable. Off the VPN or with Chrome closed, builds pile up and all announce themselves at once on reconnect. Leave this unchecked to drop anything that already happened more than two minutes ago.
SEARCH
Saves automatically.
How many levels of Jenkins folders the pipeline search walks. Raise it if jobs are nested deeply; lower it if the first search is slow. The list is cached for the browser session.
BLOCK TRIGGERING
Saves automatically.

A blocked pipeline cannot be started from the popup. Its Run button becomes Open and takes you to the job in Jenkins instead.

One regular expression per line, matched against the pipeline's full path such as Frontend/web-prod-deploy, ignoring case and anywhere in the path. prod blocks anything with "prod" in it; ^Release/ only the Release folder; deploy$ only names ending in "deploy".
To block one pipeline instead, click the padlock beside its name in the popup. A pattern block cannot be undone there; change the pattern here.
WHERE THIS IS STORED
The base URL, user ID, starred pipelines and their saved parameter values live in chrome.storage.sync, so they follow your Chrome profile. The API token is deliberately kept in chrome.storage.local instead, so the credential is not uploaded to Google and copied to every machine you sign in on. Password build parameters are sent to Jenkins but never written to storage at all.
