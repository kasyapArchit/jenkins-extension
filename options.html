Jenkins Launcher

Point the extension at your Jenkins controller once, then star pipelines from the popup.

CONNECTION
No trailing job path. Include the context path if Jenkins sits behind a proxy, for example https://ci.example.com/jenkins.
API token requests are exempt from Jenkins CSRF checks. Session mode needs you logged in to Jenkins in this browser and fetches a crumb per build.
Create one at /me/security on your Jenkins.
STATUS TRACKING
Chrome will not fire alarms faster than every 30 seconds. While the popup is open, elapsed times still tick every second.
SEARCH
How many levels of Jenkins folders the pipeline search walks. Raise it if jobs are nested deeply; lower it if the first search is slow. The list is cached for the browser session.
BLOCK TRIGGERING

A safety net for the pipelines you never want to start by accident from a popup. A blocked pipeline still appears everywhere it did before, but its Run button becomes Open and takes you to the job in Jenkins instead of building it.

There are two ways to block one, and they work independently. For a single pipeline, click the padlock beside its name in the popup. For a rule that covers pipelines you have not starred, or that do not exist yet, write a pattern below.
One pattern per line. Each is a JavaScript regular expression, matched against the pipeline's full path such as Frontend/web-prod-deploy, ignoring case. A pattern matches anywhere in the path unless you anchor it, so prod blocks anything with "prod" in its name or its folder.
Useful pieces: ^ start of the path, $ end, . any character, .* any run of characters, | either-or, \. a literal dot.
Examples — prod blocks every pipeline with "prod" anywhere. ^Release/ blocks everything in the Release folder and nothing else. deploy$ blocks names that end in "deploy". prod|live|release blocks any of the three.
Type any pipeline path to see whether these patterns would block it. Nothing is saved, and the patterns above are used as they are currently typed.
Patterns cannot be overridden from the popup: a pipeline blocked by a pattern shows a padlock that will not open, and the only way to lift it is to change the pattern here. A pipeline blocked by hand can be unblocked by clicking its padlock. Blocking is enforced by the background script, not just by hiding the button, so a stale popup cannot slip a build past it.
WHERE THIS IS STORED
The base URL, user ID, starred pipelines and their saved parameter values live in chrome.storage.sync, so they follow your Chrome profile. The API token is deliberately kept in chrome.storage.local instead, so the credential is not uploaded to Google and copied to every machine you sign in on. Password build parameters are sent to Jenkins but never written to storage at all.
